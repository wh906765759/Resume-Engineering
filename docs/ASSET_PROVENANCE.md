# 素材来源与再分发边界

| 资源 | 来源/处理 | 本轮状态 |
|---|---|---|
| 网站HTML/CSS/JS | 本轮编写；按用户授权的深色模块化视觉方向制作 | 无第三方模板代码、无远程依赖 |
| 简历styles.css | 按用户要求复用其确认的排版样式 | 保留A4、字号、网格、线条；未携带正文或照片 |
| 简历HTML/JS | 本轮重新编写，绑定虚构展示数据 | 所有文本先转义后写入DOM |
| demo-data.js | 原创虚构教学样例 | 非真实人物事实库；不得用于真实投递 |
| portrait-placeholder.svg | 本轮编写的几何轮廓 | 无真人身份、无EXIF、无外链 |
| 字体 | 仅CSS字体栈，无字体二进制随包分发 | 本机字体仅用于本地预览；公开PDF前核对所用字体嵌入许可 |
| Python开发依赖 | 独立开发环境安装 | 不随模板打包；依赖声明留requirements-dev |
| Playwright/Chromium | 本地渲染与验收工具 | 不随Skill资源包分发 |

当前没有下载第三方照片、字体或模板。所有者于2026-09-09确认既有模板对外分发权及MIT许可，许可证见根目录LICENSE；上述记录不代替对后续新增资源的许可检查。
本地输出PDF和截图存入被忽略的output目录，不自动进入公开仓库。
