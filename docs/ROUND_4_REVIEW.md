# 第四轮安全加固与回归

日期：2026-09-09；版本0.4.0-local-hardening。

## 修复

1. 产物检查原来仅比较已记录文件，可能遗漏额外文件。现在比对完整集合，重建前隔离旧目录，避免将额外文件纳入新清单。
2. 隔离入口新增路径键验证；产物校验新增越界及符号链接检查。
3. 增加revoke命令，撤回用途后失效检查本地产物。
4. 模型HTTP请求禁止重定向；本地AI请求要求准确Origin，拒绝缺失来源及模糊长度编码。
5. 新增回归：额外文件不被采用、危险路径、主动撤回、重定向及无依据引用；扩展缺失Origin和超时错误脱敏检查。
