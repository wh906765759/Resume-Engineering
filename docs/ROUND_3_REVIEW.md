# 第三轮：事实驱动生成与本地问答

2026-09-09，版本0.3.0-workflow。

## 已实现

- 字段级事实投影及按用途审核：网站、AI、定向简历权限分开。
- 差异提案、旧证据保留、版本递增、变更后重新审核。
- 依赖图、文件哈希和输入指纹；未变产物复用，过期产物转入私人隔离目录。
- 工艺、NPI、质量三类示例按项目和能力排序，历史Title不变。
- 本机HTTP问答、来源校验、限流、错误分类和每次请求重新检查权限。
- 兼容聊天模型适配器；默认mock明确标记本地检索演示。

## 验证

24项Python测试通过。浏览器测试三类简历均为两个页面容器且无检测到的溢出；工艺版两页截图已人工查看。网站1440/390宽度正常，浏览器实际提交返回本地检索演示，无脚本错误。本轮未生成PDF，不能把HTML检查等同PDF验收。

修改网站脚本后的构建只生成website，复用三份简历及assistant。未测量实际Token节省百分比。

测试来源：tests/test_pipeline.py、tests/render_workflow.cjs；本地记录：output/workflow-browser-validation.json及output/workflow-*.png。

## 边界与后续

88条全虚构演示记录为字段级绑定样例，不是88项独立成果。真实资料需人工映射，不可沿用示例审批。第三方模型只经过模拟传输测试，未调用真实付费服务，未验证回答忠实度。当前为可信本机原型，不是生产服务；未提供自动资料导入、任意模板适配或Excel导出。

没有修改参考网站、个人事实库、DNS或服务器；没有创建GitHub仓库、提交或推送。第四轮建议安全加固、故障回归和真实资料映射体验，GitHub发布仍安排第五轮。
