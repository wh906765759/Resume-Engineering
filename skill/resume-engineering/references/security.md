# 安全与发布边界

当前脚本面向单用户、可信本地工作区，不面向不可信用户上传或公网多租户。工作区文件和模型端点由使用者控制；来源白名单不是身份认证。

## 已有保护

- 公开投影只取获准用途且有字段证据的内容，不导出证据定位和审核元数据。
- 产物必须匹配完整文件集合和哈希；混入文件或损坏会隔离旧目录后重建，不吸收为新发布内容。
- 隔离入口拒绝跨目录键名；产物校验拒绝符号链接和越界路径。并非对恶意本机用户的完整文件系统沙箱。
- revoke明确撤回一个事实的一种用途，并执行已有本地产物失效检查。外部副本不会自动撤回。
- AI请求要求匹配的Origin，拒绝缺失来源及不明确的长度编码。命令行客户端也需显式提供Origin；这不等于认证。
- 模型请求禁止重定向，防止携带凭证或资料转发到其他地址；超时与异常不回显内部错误。
- 模型引用编号必须来自当前检索片段，但编号有效不代表回答语义正确。

## 使用前需确认

1. 同一工作区一次只运行一个写入操作。目前没有跨进程写锁，不支持并发生成、合并或审批。
2. 端点须使用者人工确认是可信服务；尚未实现完整SSRF或DNS重绑定防护。
3. 不将HTTP演示服务器暴露公网，不通过反向代理直接充当生产服务。公网使用需认证、费用预算、负载限制、TLS及独立运维验收。
4. 提示注入不能仅凭提示词防住。真实模型需单独测试事实忠实度、责任边界、诱导泄密和错误引用，不宣称已安全通过。
5. 发布Skill只包含框架、模板和虚构数据；真实工作区、隔离历史、照片和凭证不随包分发。

审核时只加载相关测试和事实ID，避免每轮将私人全库送入模型。
